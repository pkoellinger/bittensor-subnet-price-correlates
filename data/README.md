# Data folders

| Folder | Content | In git |
|---|---|---|
| `final/` | The dataset: one CSV and one `.rds` per wave, plus the codebook | yes |
| `chain/` | Small tables read from the public archive node at pinned blocks. Reproducible without any API key | yes |
| `evidence/` | Why a coded value is what it is: episode URLs, talk mapping, post IDs with codes, link sources, snapshot hashes | yes |
| `manual/` | Coding tables filled by two independent coders, with evidence URL and quote per fact | yes |
| `intermediate/` | One table per collection script, including wallet-level rows | no |
| `raw/` | API response caches (Taostats, GitHub, X, web pages) and the call ledger | no |

`raw/` and `intermediate/` are regenerated by the scripts in `collect/`. They are kept out of git because they contain wallet-level rows and third-party API responses. Post text from X is never committed; only post IDs are.
